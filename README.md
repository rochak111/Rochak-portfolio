# Rochak Bhattarai Portfolio

Modern portfolio rebuilt with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Push to the `main` branch and enable **GitHub Pages → GitHub Actions** in repository settings. The included workflow builds and deploys the `dist` directory while retaining the custom domain in `CNAME`.
